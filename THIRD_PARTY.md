## External program: XFOIL

XFOIL 6.99 (M. Drela and H. Youngren, GPL) is the reference of the benchmark. It is run only as
an external program through a subprocess with a timeout (`foil_lab/benchmark/xfoil.py`). No
XFOIL source code was read to write Foil-Lab, and none is copied, translated, linked or
distributed. The reference polars it produced are committed as data with their provenance
(`src/foil_lab/data/reference/xfoil/`).

## Data downloaded on demand (not bundled)

- UIUC Airfoil Coordinates Database (M. Selig, University of Illinois at Urbana-Champaign),
  https://m-selig.ae.illinois.edu/ads/coord_database.html. `Airfoil.from_name` and the benchmark
  sections Clark Y and E387 download single files into a local cache
  (`~/.cache/foil-lab/airfoils`); the benchmark checks their SHA-256. Use follows the
  database's own terms.

## Data in the repository

- Williams, B. R., "An Exact Test Case for the Plane Potential Flow About Two Adjacent Lifting
  Aerofoils", ARC R&M 3717, HMSO, 1973: values transcribed from its tables as test data
  (`tests/data/williams/`), used only by the tests of the exact two-element solution.
- XFOIL reference polars (see above), generated for this project.
- NACA sections are generated by Foil-Lab's own code from the published equations; no
  coordinates are copied.
